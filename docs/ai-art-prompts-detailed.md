## 🎯 Technical Parameters Explained

### Midjourney Parameters:
- `--ar 21:9` or `--ar 16:9`: Aspect ratio (ultra-wide vs standard)
- `--s 300-800`: Stylization (lower = more literal, higher = more artistic)
- `--q 1-2`: Quality (1 = faster/cheaper, 2 = better detail)
- `--c 5-35`: Chaos (variation in results, low = consistent, high = experimental)

### Why These Specific Values:
- **Low stylization (300-500)**: For backgrounds (subtle, won't compete)
- **Medium stylization (600-750)**: For hero images (artistic but controlled)
- **Low chaos (5-15)**: For minimalist pieces (consistency key)
- **Medium chaos (20-35)**: For organic abstractions (variation desired)

## 🎨 Post-Processing Script

Nina's color correction technique in Python:

```python
from PIL import Image
import numpy as np

def correct_ai_colors(input_path, output_path):
    """
    Replace off-white backgrounds with navy, a common AI generation issue
    """
    img = Image.open(input_path).convert('RGB')
    pixels = np.array(img)

    # Target navy color #0f172a
    navy = np.array([15, 23, 42])

    # Replace pixels in range 240-255 (off-white) with navy
    off_white_mask = (pixels > 240).all(axis=2)
    pixels[off_white_mask] = navy

    # Optional: Replace yellowish tones (common GPT-5 artifact)
    # Yellow range: R > 200, G > 180, B < 100
    yellow_mask = (pixels[:,:,0] > 200) & (pixels[:,:,1] > 180) & (pixels[:,:,2] < 100)
    pixels[yellow_mask] = navy

    # Save corrected image
    corrected = Image.fromarray(pixels.astype('uint8'))
    corrected.save(output_path, quality=95, optimize=True)
    print(f"Corrected image saved to {output_path}")

# Usage
correct_ai_colors('generated.png', 'corrected.png')
```
