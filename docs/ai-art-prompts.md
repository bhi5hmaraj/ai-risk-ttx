## Technical Specifications

### For Web Use
- **Aspect Ratios**:
  - 21:9 for ultra-wide hero images
  - 16:9 for standard hero sections
  - 4:3 for card backgrounds

- **Resolution**: Generate at 2560x1440 minimum, scale down for web

- **Format**: Export as WebP with fallback PNG
  - WebP provides 25-35% smaller file sizes
  - Critical for fast page loads

- **Color Correction** (Nina's tip):
  If Midjourney generates off-white backgrounds (common bug), use Python post-processing:
  ```python
  # Replace off-white with target navy
  img = Image.open('generated.png')
  img = img.convert('RGB')
  pixels = np.array(img)
  # Replace RGB(240-255) range with RGB(15, 23, 43) navy
  mask = (pixels > 240).all(axis=2)
  pixels[mask] = [15, 23, 43]
  ```
